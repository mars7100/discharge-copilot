The solution

A cited draft the resident can check, correct and approve.

01Read all notes in parallel
02Flag conflicts and ask the resident
03Draft sections, every claim cited
04Ask questions, propose corrections
05Approve and export to Word
It never guesses between conflicting notes, and nothing is final until a clinician approves it.

Technology

How it works, and what is not real yet.

How it works

  • API-first FastAPI backend: the UI is one client
  • LangGraph pipelines run notes and sections in parallel
  • Every cited quote is checked word for word against its source
  • React UI streams the draft and answers

Limitations

  • Synthetic notes only, no real patient data
  • No EHR integration yet
  • Not HIPAA-compliant or clinically validated yet
  • Voice input not in the current UI
